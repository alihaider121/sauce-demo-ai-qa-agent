Sauce Demo AI QA Agent - Project Progress Summary

1. What this project is

This repository is an autonomous AI-powered QA project built around Playwright and Sauce Demo. The purpose is to observe the site, identify scenarios, generate tests, execute them, detect whether a failure is a real app bug or a broken test, repair the tests when needed, and summarize the outcome in a report.

3. File-by-file explanation

playwright.config.ts

This config defines project defaults such as the base URL, browser target, data-test handling, and JSON/HTML reporting.

pages/LoginPage.ts

This page object wraps the login interaction. It contains user, password, login button, and error locators for clean reuse across tests.

pages/InventoryPage.ts

This page object handles inventory actions like product listing, title validation, cart badge, and adding items to the cart.

pages/CheckoutPage.ts

This file covers the typical checkout flow and validation checks, including form filling and the final order completion step.

pages/CartPage.ts

This file was added to support cart-level actions such as checking cart items, opening checkout, and removing products.

agent/observe.ts

This is the observation stage. It logs in, navigates through the main pages, and records accessibility snapshots and data-test values for the agent.

agent/prompts.ts

This stores the model prompts for planning tests, writing tests, and healing broken ones.

agent/llm.ts

This file connects to GitHub Models using the OpenAI-compatible interface. It handles rate-limit retries and request formatting.

agent/guardrails.ts

This is the safety layer. It enforces rules like only writing inside the generated tests folder, requiring assertions, blocking test-only or network-mocking patterns, and rejecting weakened fixes that remove assertions.

agent/run.ts

This is the main orchestration file. It drives the entire flow: observe -> plan -> generate -> run -> heal -> report.

agent/report.ts

This file generates the summary of passed tests, healed tests, app bugs found, quarantined failures, and rejected guardrail cases.
